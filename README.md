# 🃏 Python Blackjack Game

Pythonで制作した、ターン制の簡易ブラックジャックゲームです。  
プレイヤー、CPU、ディーラーの3者で対戦を行います。

---

## 📌 概要 (Overview)

* **デッキ構築とリアルなドロー**: ♠・♥・♦・♣の4種類（計52枚）の山札を作成してシャッフルし、カードを引くたびに山札から消費される仕様にしています（同じカードは排出されません）。
* **柔軟なエース（A）の計算**: Aは手札の状況に応じて「1」または「11」として最適に扱われます。21を超えた場合はバーストとして敗退します。
* **ランダムなターン順**: ゲーム開始時、プレイヤーとCPUのどちらが先に行動するかがランダムで決定されます。
* **対戦フロー**: プレイヤーとCPUのターンが終了した後、最後にディーラーがカードを引き、最終スコアを比較して勝敗を決定します。

## 🚀 実行方法 (How to Run)

1. **リポジトリをクローン（またはダウンロード）します。**
   ```bash
   git clone https://github.com/Rmelon628/blackjack_prototype_2026.git
   cd blackjack-python
   ```

2. **プログラムを実行します。**
   ```bash
   python main.py
   ```
   *(環境によっては `python3 main.py`)*

---

## 🎮 操作方法 (How to Play)

1. **ゲームの開始**  
   起動後、「`enterを押してブラックジャックを開始`」と表示されたら **Enterキー** を押します。
   
2. **ターンの決定**  
   CPUとプレイヤーのどちらから行動を開始するかが自動（ランダム）で決まります。

3. **プレイヤーの操作**  
   プレイヤーのターンになると、現在の所持カードが表示されます。  
   「`カードを引きますか？(はい(yes)/いいえ(no))`」と表示されたら、以下のように入力します。
   * **カードを引く場合**: `y` または `はい` を入力
   * **カードを引かない場合**: `n` やその他の文字を入力

4. **勝敗の決定**  
   プレイヤーのターン終了後、CPUが自動で行動し、最後にディーラーがカードを引きます。全員のターン終了後、各プレイヤーの最終スコア、所持カード、および勝者が画面に表示されます。
